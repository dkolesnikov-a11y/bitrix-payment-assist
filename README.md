# Помощник по оплатам — домашнее задание

Учебная обезличенная копия проекта бота Битрикс24. Бот принимает изображения платежей, распознаёт данные через OCR, подбирает счета и проверяет проведение оплаты. При неоднозначности запрашивает выбор и подтверждение пользователя.

## Проверка без доступа к CRM

Требуется Node.js 24 или новее. Внешних npm-зависимостей нет.

```sh
npm test
npm run demo
```

Тесты используют подставные API и временные SQLite-базы. Демо работает локально без ключей, отправки сообщений и записи в CRM; демонстрирует обработку события без подключённого OCR, а не полное распознавание платежа.

## Что реализовано

- Приём событий, контроль доступа и обработка изображений.
- OCR, проверка суммы и даты, извлечение номеров счетов.
- Подбор по плательщику, номеру счёта и остатку; обработка частичных оплат.
- Выбор счёта и подтверждение получателя через кнопки.
- Защита от повторной оплаты, журнал операций, проверка результата и восстановление после неопределённого ответа API.
- Локальные регрессионные тесты и сервер проверки состояния.

## Структура

- `src/` — логика бота, OCR и адаптер API.
- `test/` — тесты бизнес-логики.
- `tools/payment-safety/` — журнал и защита платежных операций с тестами.
- `deploy/` — сервер состояния и иконка.
- `config.example.json` — пример с выключенной записью и отправкой сообщений.

## Ограничения учебной версии

Адрес рабочего портала заменён на `example.invalid`, названия контрагентов и ИНН в тестах обезличены. Числовые идентификаторы и структура полей CRM служат тестовыми параметрами и не предоставляют доступ. Проект содержит привязки к конкретной схеме CRM: типам сущностей, стадиям, пользовательским полям и допустимым получателям. Для другого портала их необходимо адаптировать, включая проверку конфигурации и ссылки на счета. Полная приёмка в реальной CRM этим тестовым прогоном не подтверждается.

Рабочие конфигурации, ключи, базы, скриншоты, журналы, внутренние отчёты, разовые скрипты эксплуатации и прежняя Git-история в эту копию не включены. Для проверки домашнего задания запускать `npm start` или регистрацию бота не требуется.
