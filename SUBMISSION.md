## Передача через GitHub

Создайте пустой репозиторий GitHub. Откройте терминал именно в папке этой учебной копии и выполните, подставив свой URL:

```sh
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

После загрузки отправьте куратору ссылку на репозиторий. Для закрытого репозитория предоставьте куратору доступ. Исходный рабочий репозиторий для этой отправки не используется.
